# Frontend 变更记录

> 记录前端界面的主要改动。变更记录撰写规范参见 [CLAUDE.md](../CLAUDE.md)。

## 2026-10-14 (v2.6.0)
- **新增**：任务流程预览弹窗与结构化预览接口，支持 Mermaid 流程图展示与节点详情查看，并补齐流程相关多语言文案。
- **新增**：任务运行中徽标可直接打开实时日志，运行已结束的任务给出友好提示。
- **修复**：修复任务列表页 `isRunInProgress` 未导入导致的报错，并修正任务运行态判定与组件销毁逻辑。

## 2026-10-07 (v2.5.1)
- **修复**：WebDAV 用户名/密码输入增加 `autocomplete="off"` / `autocomplete="new-password"` 与防注入属性，阻断密码管理器自动填充引发的脏表单误报（Issue #12）。
- **优化**：TaskForm 编辑模式展示多目标执行类型只读说明框，提供多会话/单会话说明与克隆引导（Issue #12）。
- **修复**：账号列表引入 `compareAccountNames` 自然排序，解决纯数字账号字典序错位（Issue #12）。

## 2026-10-01
- **优化**：任务实时日志面板新增「WS 实时 / 轮询中 / 连接中」状态徽标。
- **修复**：优化流式日志轮询生命周期，丢弃跨代旧响应，避免切换任务时日志串台。
- **修复**：日期选择器改为展开时才注册全局点击事件，并在组件卸载时彻底清理，防止事件监听泄漏。

## 2026-09-30
- **优化**：重构数据管理界面为 3-Tab 布局，支持备份预设与本地文件直接下载。

## 2026-08-05
- **优化**：完善账号列表、任务管理、日志页面与设置面板的交互体验与状态响应。
