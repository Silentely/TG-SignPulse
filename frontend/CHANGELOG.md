# Frontend 变更记录

## 2026-10-01
- **优化**：任务实时日志面板新增「WS 实时 / 轮询中 / 连接中」状态徽标。
- **修复**：优化流式日志轮询生命周期，丢弃跨代旧响应，避免切换任务时日志串台。
- **修复**：日期选择器改为展开时才注册全局点击事件，并在组件卸载时彻底清理，防止事件监听泄漏。

- **优化**：重构数据管理界面为 3-Tab 布局，支持备份预设与本地文件直接下载。
