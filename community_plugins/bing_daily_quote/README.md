# 必应每日一图与名言 (bing_daily_quote)

主动执行型插件。每天在定时打卡流中调用，自动获取微软必应 (Bing) 今日壁纸背景故事、地点与格言，并发送至指定 Telegram 会话。

## 适用场景

- 晨间自动打卡时，附带每日问候语，让打卡行为更自然，模拟真实用户的日常早起问候。
- 定时向群组播报每日一句名言或今日壁纸故事。

## 参数说明

| 参数项 | 类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `greeting_prefix` | 字符串 | `☀️ 每日晨安名言：` | 消息顶部的问候引导语 |
| `include_copyright` | 布尔值 | `true` | 是否在名言下方附加必应摄影地点与版权文字 |
