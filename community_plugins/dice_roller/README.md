# 趣味掷骰子与抽签 (dice_roller)

响应式插件。实时监控指定群组或私聊中的 `/roll`、`/dice` 或自定义口令，随机生成点数并即刻在 Telegram 中应答。

## 触发命令

- `/roll`：默认掷出 1~100 的随机数
- `/roll 20`：掷出 1~20 的二十面骰
- `/dice 6`：掷出 1~6 的六面骰

## 参数说明

| 参数项 | 类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `max_sides` | 数字 | `100` | 默认的最大骰子面数 |
| `reply_prefix` | 字符串 | `🎲 骰子掷出了：` | 回显结果前缀 |
