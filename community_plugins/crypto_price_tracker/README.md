# 加密货币行情解析助手 (crypto_price_tracker)

响应式插件。实时监控目标会话中由各类 Bot、行情看板或快讯机器人推送的文本消息，自动提取指定代币（如 BTC、ETH、TON、SOL 等）的实时法币价格，并存储至插件独立数据库。

## 参数说明

| 参数项 | 类型 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- |
| `target_symbol` | 字符串 | `BTC` | 欲监听的数字货币代码，如 `BTC`, `ETH`, `SOL` |
| `track_history` | 布尔值 | `true` | 是否将最新价格与更新时间写入插件持久化存储 |
