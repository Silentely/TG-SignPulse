# Backend 变更记录

> 记录后端服务的主要改动。变更记录撰写规范参见 [CLAUDE.md](../CLAUDE.md)。

## 2026-10-28 (v2.7.0)
- **新增**：JEV 语义决策引擎后端能力 —— 新增 `/api/semantic` 配置、测试、统计、观测与建议接口，支持按钮语义匹配兜底、三态熔断、本地缓存、密钥加密保存与外送保护，并可一键采纳规则建议更新任务配置。
- **新增**：任务运行产物脱敏留存与回放夹具、Bot 契约漂移检测、运行手册诊断与操作接口。
- **新增**：通知投递回执 outbox，可查询投递记录并对异常回执进行对账。
- **新增**：账号生命周期变更暂存与回滚；备份清单快照、恢复前置校验与可取消的恢复流程。
- **新增**：流程引擎按话题隔离消息事件并记录修订，持久化并行分支结果、变量冲突与部分/未知执行结果。
- **优化**：回复流程支持机器人回复等待与忙碌重试，失败重试从流程入口重新开始。
- **修复**：修复旧版插件存储命名空间迁移、插件清单校验、旧账号删除保护及备份恢复取消的边界问题。

## 2026-10-19 (v2.6.2)
- **新增**：关键词监听与工作流引擎全面支持多目标顺序点击（Action 3 与 Action 7），多步点击之间注入拟人随机延迟并在步间刷新消息键盘状态（Issue #15）。
- **优化**：重构 `parse_click_targets` 与 `clean_text_for_match`，修复纯 Emoji 清洗清空与单按钮保护切分；新增 `SequenceClickPartialError` 并与 PulseFlowEngine 及 SignerRunner 联动，避免部分点击成功后因超时等异常误触发非幂等重试。

## 2026-10-16 (v2.6.1)
- **修复**：WebDAV 客户端各接口启用 `follow_redirects=True`，探测集合目录时自动补齐末尾斜杠，修复服务商重定向返回 HTTP 301 探测失败问题（Issue #14）。
- **新增**：全局设置与 WebDAV 客户端新增 `webdav_skip_ssl_verify` 开关（默认关闭），开启时传递 `verify=False` 并放宽 SSRF 私网校验，支持内网自建 WebDAV 与自签名证书（Issue #14）。

## 2026-10-14 (v2.6.0)
- **新增**：执行引擎接线改造 —— 任务会话配置支持 `flow_graph`、`steps`、`actions` 三路互斥输入，新增自适应引擎路由与图结构静态校验（全图环检测、未知节点类型拒绝、节点 ID 一致性、节点总数预算上限）。
- **新增**：PulseFlow (v4) 引擎增强 —— 并行分支调度、Subflow 嵌套执行、执行断点恢复与状态序列化、FloodWait 自适应自愈、连续失败熔断与全局统一超时、生命周期钩子与节点级条件守卫、敏感凭据脱敏。
- **新增**：v3→v4 灰度切流开关，支持任务级引擎覆盖、全局开关联动与运行时状态查询。
- **新增**：官方内置插件 `stock_sniper`（商店 Bot 补货监控与自动抢购助手）。
- **优化**：AI 动作超时放宽至 60 秒并透传到 runner 等待逻辑，视觉识别默认超时调整为 25 秒。
- **修复**：修复任务运行器自阻塞问题（改为按 `run_id` 判定是否已在运行）及执行引擎配置路由、节点输出状态的边界错误。

## 2026-10-07 (v2.5.1)
- **修复**：新增 `natural_sort_key` 自然排序算法，统一 `tg_session` 与 `accounts` 列表排序，修复纯数字账号（1, 9, 11）字典序倒挂（Issue #12）。
- **修复**：Client 新增 `_safe_close_client` 安全关闭底层存储，重命名时在 `finally` 块中关闭连接避免 SQLite 锁死（Issue #12）。
- **修复**：`rename_account` 覆盖 0 字节目标无效文件并同步迁移头像缓存；`list_accounts` 与 `account_exists` 自动检测并清理 0 字节幽灵 session（Issue #12）。

## 2026-10-01
- **修复**：修复限流器高并发下新 Key 计数清零的漏洞，增加总容量上限防内存泄漏。
- **修复**：修复 ChatOps 停止时的 CancelledError 异常，优化优雅退出逻辑。
- **优化**：增加 Telegram 429 频率限制指数退避重试，完善后台任务异常捕获与回收。

## 2026-09-30
- **架构**：移除 S3 兼容对象存储支持，备份灾备统一收敛至 WebDAV 与本地下载。
- **优化**：重构系统数据管理页面，提供常用备份预设与一键归档下载。

## 2026-09-28
- **修复**：修复删除通配任务误伤同名普通任务的 bug。
- **修复**：修复特殊字符文件名编码迁移导致的旧历史记录丢失问题。
- **安全**：增加 JWT 世代号吊销机制、关键词正则 ReDoS 超时保护、外部 Webhook 公网地址校验与配置导出敏感信息脱敏。

## 2026-08-05
- **优化**：完善后端任务流水线、历史索引与关键词监听的接口规范与文档整理。
