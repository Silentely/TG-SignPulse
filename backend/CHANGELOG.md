# Backend 变更记录

> 记录后端服务的主要改动。变更记录撰写规范参见 [CLAUDE.md](../CLAUDE.md)。

## 2026-11-14 (未发布)
- **优化**：社区插件开关按「设置文件显式键 > 环境变量 > 默认关闭」取值，`GET /api/config/settings` 新增只读来源字段 `allow_community_plugins_source`；保存无关设置不再把环境变量推导值固化进设置文件；保存开关时立即重建插件注册表，社区与市场插件当下停止或恢复，执行入口再增加一道运行时门禁校验；重载保留仍在使用插件的运行指标与调用历史。
- **修复**：配置导入/导出不再把开关推导值和只读来源字段写入设置文件；市场条目新增 `runtime_loaded`，区分「仓库目录加载」与「运行时已注册」。

## 2026-11-12 (v2.9.0)
- **新增**：素材数据字典使用统计，抽词时累计每本字典的使用次数与最近使用时间，新增 `GET /api/data-dict/stats`；内置问候、签到、祝福、感谢、群聊闲聊五组词条模板，支持一键引用且不覆盖同名字典。
- **新增**：任务执行策略独立配置，集中管理执行超时、账号冷却、流程重试、历史保留与 AI 视觉超时/重试/思考度。
- **新增**：通用设置新增「强制 Telegram 连接使用代理」开关，开启后未配置代理的账号会被拒绝登录与执行。
- **新增**：机器人通知新增 ChatOps 指令开关与管理员 user_id 白名单。
- **新增**：AI 视觉接入 Cloudflare Workers AI，支持账户字段、模型候选、许可授权自动处理与凭据切换保护；选项识别支持中英双语映射、前缀提取与未知选项并发翻译缓存。
- **新增**：社区插件默认不加载，需开启 `allow_community_plugins` 或设置 `PLUGINS_ALLOW_COMMUNITY=true`；新增 `mini_app_claim` 社区插件；插件新增 `request_web_view` 能力与 `web_app` 权限，插件异常按账号/目标/能力三层分类。
- **优化**：任务执行前多级预热会话 peer 并合并 `chats_cache.json`，放行正负两种合法 `chat_id`；等待机器人回复的默认成功/失败规则与重试关键词扩充，签到流程统一并延长超时预算。
- **优化**：JEV 动作辅助默认开启，运行时按配置目录解析依赖并细化失败诊断。
- **修复**：修复直接解析模式下会话 `chat_id` 被改写导致话题上下文错乱、备用 AI 节点脱敏 URL 回存丢失配置、AI 请求失败回显完整 Token 等安全问题；数据字典写入拒绝下划线开头的系统保留名，删除不存在的字典返回 404。

## 2026-11-07 (v2.8.1)
- **修复**：插件 Context v2 在身份不完整时回退旧版共享存储命名空间并输出一次性告警；worker 代理与宿主侧行为对齐，存储作用域参数统一校验。
- **修复**：官方内置插件补齐 `context_version=2`、`plugin_api`、`min_app_version` 与权限清单。
- **修复**：修复插件加载缓存（`_loaded_files`）跨测试用例泄漏导致内置插件注册丢失的问题。

## 2026-11-07 (v2.8.0)
- **不兼容**：插件加载门禁强制要求 Context v2。非官方内置白名单插件必须声明 `context_version=2`、`plugin_api`、`min_app_version` 与权限数组，否则主进程与 worker 均会拒绝加载。
- **不兼容**：执行引擎单轨切换至 PulseFlow v4。任务级与全局经典引擎配置不再参与常规路由，仅保留 `PULSEFLOW_ENGINE_OVERRIDE=classic` 紧急回滚；图结构任务在回滚时显式报错。
- **新增**：新增 `backend/services/plugins.py`，以 `PluginService` 统一 37 个插件域方法，路由层不再直接操作插件存储与运行时。
- **新增**：插件运行时新增类型化 RPC 异常与跨进程异常重建、按作用域隔离的存储、全局存储、发送图片/文档、置顶/转发、已读与输入状态等能力。
- **新增**：流程执行增加操作回执与幂等校验，瞬时错误重试前确认副作用是否已经发生；FloodWait 与临时异常按回执状态保护。
- **新增**：新增任务配置 dry-run 扫描工具，可在升级前检查任务与经典引擎的兼容情况。
- **优化**：账号锁释放前校验租约归属；新增对等端预热缓存；任务取消时保证锁释放。
- **优化**：日志上下文支持线程池透传，WebSocket 支持通配订阅并按 run_id 与序号去重。
- **修复**：修复备份恢复时调度锁检测错误、挂载兼容性问题与凭证安全防御缺陷。

## 2026-10-28 (v2.7.0)
- **新增**：JEV 语义决策引擎后端能力 —— 新增 `/api/semantic` 配置、测试、统计、观测与建议接口，支持按钮语义匹配兜底、三态熔断、本地缓存、密钥加密保存与外送保护，并可一键采纳规则建议更新任务配置。
- **新增**：任务运行产物脱敏留存与回放夹具、Bot 契约漂移检测、运行手册诊断与操作接口。
- **新增**：通知投递回执 outbox，可查询投递记录并对异常回执进行对账。
- **新增**：账号生命周期变更暂存与回滚；备份清单快照、恢复前置校验与可取消的恢复流程。
- **新增**：流程引擎按话题隔离消息事件并记录修订，持久化并行分支结果、变量冲突与部分/未知执行结果。
- **优化**：回复流程支持机器人回复等待与忙碌重试，失败重试从流程入口重新开始。
- **修复**：修复旧版插件存储命名空间迁移、插件清单校验、旧账号删除保护及备份恢复取消的边界问题。

## 2026-10-19 (v2.6.2)
- **新增**：关键词监听与工作流引擎全面支持多目标顺序点击（Action 3 与 Action 7），多步点击之间注入拟人随机延迟并在步间刷新消息键盘状态（Issue #15）。
- **优化**：重构 `parse_click_targets` 与 `clean_text_for_match`，修复纯 Emoji 清洗清空与单按钮保护切分；新增 `SequenceClickPartialError` 并与 PulseFlowEngine 及 SignerRunner 联动，避免部分点击成功后因超时等异常误触发非幂等重试。

## 2026-10-16 (v2.6.1)
- **修复**：WebDAV 客户端各接口启用 `follow_redirects=True`，探测集合目录时自动补齐末尾斜杠，修复服务商重定向返回 HTTP 301 探测失败问题（Issue #14）。
- **新增**：全局设置与 WebDAV 客户端新增 `webdav_skip_ssl_verify` 开关（默认关闭），开启时传递 `verify=False` 并放宽 SSRF 私网校验，支持内网自建 WebDAV 与自签名证书（Issue #14）。

## 2026-10-14 (v2.6.0)
- **新增**：执行引擎接线改造 —— 任务会话配置支持 `flow_graph`、`steps`、`actions` 三路互斥输入，新增自适应引擎路由与图结构静态校验（全图环检测、未知节点类型拒绝、节点 ID 一致性、节点总数预算上限）。
- **新增**：PulseFlow (v4) 引擎增强 —— 并行分支调度、Subflow 嵌套执行、执行断点恢复与状态序列化、FloodWait 自适应自愈、连续失败熔断与全局统一超时、生命周期钩子与节点级条件守卫、敏感凭据脱敏。
- **新增**：v3→v4 灰度切流开关，支持任务级引擎覆盖、全局开关联动与运行时状态查询。
- **新增**：官方内置插件 `stock_sniper`（商店 Bot 补货监控与自动抢购助手）。
- **优化**：AI 动作超时放宽至 60 秒并透传到 runner 等待逻辑，视觉识别默认超时调整为 25 秒。
- **修复**：修复任务运行器自阻塞问题（改为按 `run_id` 判定是否已在运行）及执行引擎配置路由、节点输出状态的边界错误。

## 2026-10-07 (v2.5.1)
- **修复**：新增 `natural_sort_key` 自然排序算法，统一 `tg_session` 与 `accounts` 列表排序，修复纯数字账号（1, 9, 11）字典序倒挂（Issue #12）。
- **修复**：Client 新增 `_safe_close_client` 安全关闭底层存储，重命名时在 `finally` 块中关闭连接避免 SQLite 锁死（Issue #12）。
- **修复**：`rename_account` 覆盖 0 字节目标无效文件并同步迁移头像缓存；`list_accounts` 与 `account_exists` 自动检测并清理 0 字节幽灵 session（Issue #12）。

## 2026-10-01
- **修复**：修复限流器高并发下新 Key 计数清零的漏洞，增加总容量上限防内存泄漏。
- **修复**：修复 ChatOps 停止时的 CancelledError 异常，优化优雅退出逻辑。
- **优化**：增加 Telegram 429 频率限制指数退避重试，完善后台任务异常捕获与回收。

## 2026-09-30
- **架构**：移除 S3 兼容对象存储支持，备份灾备统一收敛至 WebDAV 与本地下载。
- **优化**：重构系统数据管理页面，提供常用备份预设与一键归档下载。

## 2026-09-28
- **修复**：修复删除通配任务误伤同名普通任务的 bug。
- **修复**：修复特殊字符文件名编码迁移导致的旧历史记录丢失问题。
- **安全**：增加 JWT 世代号吊销机制、关键词正则 ReDoS 超时保护、外部 Webhook 公网地址校验与配置导出敏感信息脱敏。

## 2026-08-05
- **优化**：完善后端任务流水线、历史索引与关键词监听的接口规范与文档整理。
