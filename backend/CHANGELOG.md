# Backend 变更记录

> 记录后端服务的主要改动。变更记录撰写规范参见 [CLAUDE.md](../CLAUDE.md)。

## 2026-10-01
- **修复**：修复限流器高并发下新 Key 计数清零的漏洞，增加总容量上限防内存泄漏。
- **修复**：修复 ChatOps 停止时的 CancelledError 异常，优化优雅退出逻辑。
- **优化**：增加 Telegram 429 频率限制指数退避重试，完善后台任务异常捕获与回收。

## 2026-09-30
- **架构**：移除 S3 兼容对象存储支持，备份灾备统一收敛至 WebDAV 与本地下载。
- **优化**：重构系统数据管理页面，提供常用备份预设与一键归档下载。

## 2026-09-28
- **修复**：修复删除通配任务误伤同名普通任务的 bug。
- **修复**：修复特殊字符文件名编码迁移导致的旧历史记录丢失问题。
- **安全**：增加 JWT 世代号吊销机制、关键词正则 ReDoS 超时保护、外部 Webhook 公网地址校验与配置导出敏感信息脱敏。

## 2026-08-05
- **优化**：完善后端任务流水线、历史索引与关键词监听的接口规范与文档整理。
